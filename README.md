# 质检优化助手（QC Plugin）

Chrome 扩展（Manifest V3），运行在 ICS 质检工作台页面上，为质检规则优化提供两类能力：

- **模式 A · 规则优化对话**：与质检规则 Agent 对话，输入业务线 + 质检点（可选 task id / 优化方向），自动清会话发送提示词，Agent 输出结束后提取「优化结果」格式化成卡片，并支持一键跳转页面上的质检点。
- **模式 B · 评测集生成**：输入一个或多个复核任务 ID，复用页面登录态自动抓取评分、服务记录与质检点，生成符合评测集模板的 Excel 文件。

当前版本：**v5.0.7**（本版新增「规则版本」单选，见下方版本历史）。

---

## 功能说明

### 模式 A · 与质检规则 Agent 对话

悬浮窗内的对话框提供以下输入项：

| 输入项 | 说明 |
|---|---|
| 业务线 * | 下拉必选（Antom AGH-天猫飞猪 / CN Trade / WFSEA 等固定列表） |
| 质检点 * | 必填，如 `G21`，支持回车提交 |
| **规则版本**（v5.0.7 新增） | 单选二选一：**发布版本**（默认）/ **草稿版**。每次点「发送」时，在提示词中质检点取值后追加 `（正式版）` 或 `（草稿版）` |
| 优化类型 | 二选一下拉：**Task ID**（走 RCA 链路）/ **优化方向**（直发链路附加一行） |
| Task ID | 复核 id，可多个（逗号/空格分隔），选填 |
| 优化方向 | 直接描述优化诉求，选填 |

两条链路（均自动新建会话后发送）：

1. **直发链路**（无 task id）：发送「帮我优化 业务线/质检点/优化方向」→ Agent 输出结束后格式化成卡片。
2. **RCA 链路**（有 task id）：先发送 RCA 提示词生成根因分析 → RCA 展示为确认态（只读 + 120 秒倒计时，可点「编辑」修改保存）→ 点「直接发送」或倒计时到期自动发送优化请求。

辅助能力：

- **🎯 质检点**：卡片上解析出质检点编码后，一键在规则管理页搜索定位并高亮。
- **🔄 重载格式**：Agent 输出加载不全导致格式化不完整时，重新从页面提取并格式化。
- 已填内容在面板重渲染时回显，不丢失；发送前若 Agent 仍在生成会先点「停止」再发。

### 模式 B · 复核任务 ID 生成评测集 Excel

- 输入一个或多个复核任务 ID（逗号/空格分隔）。
- 自动抓取评分数据与服务记录详情（要求所有任务渠道一致；邮件渠道额外拼装 recore_detail）。
- 输出符合评测集模板的 Excel 文件，并列出质检点编码列。

### 通用

- 悬浮窗可拖拽、可缩放、可收起。
- 「先判断当前激活页」：仅处理前台焦点页签发起的请求，避免正式/预发多标签页互相触发。

## 安装

1. 下载并解压本目录（或 Releases 中的 `qc-plugin-vX.Y.Z.zip`）。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录。
4. 打开 ICS 页面（正式或预发），页面右侧出现悬浮窗即安装成功。

已配置 `update_url` 自动更新；插件启用后可自动检测新版本。

## 目录结构

| 文件 | 职责 |
|---|---|
| `manifest.json` | MV3 清单：版本号、权限、注入规则、update_url |
| `content.js` | 悬浮窗 UI 与主逻辑（模式 A/B 对话框、结果格式化、质检点跳转） |
| `background.js` | Service Worker：消息分发（`qc-drive` / `qc-query-rules` / `qc-version-history` / `qc-rca-agent` / `qc-evalset` / `qc-track` 等） |
| `hook.js` | MAIN world 注入（`document_start`），页面侧请求/会话辅助 |
| `reporter.js` | 埋点上报模块：事件到达立即逐条 POST 到钉钉连接器 Webhook（不依赖定时器，规避 MV3 SW 空销毁问题），字段平铺、PII 脱敏（ctoken / access_token / 邮箱）、最多 2 次退避重试 |
| `panel.css` | 悬浮窗样式 |
| `extension.xml` | 自动更新 manifest |
| `icon*.png` | 图标（16/48/128） |

### 埋点

页面上的关键操作（提交、RCA 直接发送、格式化、定位质检点、重载格式等）通过 `qcTrack` → background `qc-track` → `reporter.js` 上报，事件字段包含 `event_name`、`event_time`、`plugin_version`、`biz`、`qp`、`result` 等，写入钉钉连接器对应的 AI 表格。埋点失败不影响主流程。

## 权限说明

| 权限 | 用途 |
|---|---|
| `tabs` / `scripting` + `<all_urls>` | 向 ICS 页签注入脚本、驱动页面自动化（清会话、输入、发送、提取结果） |
| 内容脚本匹配 | 仅注入 `https://ics.alipay.com/*` 与 `https://ics-site-pre.alipay.com/*` |

## 发布（维护者）

1. 确认变更已合并到发布分支。
2. 更新 `manifest.json` 中的 `version` 并提交。
3. 本地打包为 zip，计算校验和：
   ```bash
   shasum -a 256 qc-plugin-vX.Y.Z.zip > qc-plugin-vX.Y.Z.zip.sha256
   ```
4. 创建 GitHub Release 并附带资产：
   ```bash
   gh release create vX.Y.Z qc-plugin-vX.Y.Z.zip --title "vX.Y.Z — 质检优化助手" --notes-file RELEASE_NOTES.md
   ```
5. 验证：干净环境安装插件，确认 `update_url` 指向的更新 manifest 可访问、自动更新可触发。
